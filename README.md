<summary><b>등급(Rank)은 어떻게 계산되나요?</b></summary>

<br>

6개 지표를 각각 **전 세계 GitHub 사용자의 중앙값**과 비교해 0~1점으로 환산하고,
가중치를 곱해 평균낸 뒤 **상위 몇 %** 인지를 구합니다. 그 백분위에 따라 등급 문자가 정해집니다.

| 등급 | 상위 | | 등급 | 상위 |
| :---: | ---: | --- | :---: | ---: |
| `S` | 1% | | `B` | 62.5% |
| `A+` | 12.5% | | `B-` | 75% |
| `A` | 25% | | `C+` | 87.5% |
| `A-` | 37.5% | | `C` | 100% |
| `B+` | 50% | | | |

**지표별 가중치와 기준치**

| 지표 | 가중치 | 기준치 | 증가 곡선 |
| :--- | :---: | ---: | :--- |
| Stars | 4 | 50 | 완만 — 인기 지표라 천천히 오름 |
| Pull Requests | 3 | 50 | 가파름 |
| Commits | 2 | 250 | 가파름 |
| Issues | 1 | 25 | 가파름 |
| Code Reviews | 1 | 2 | 가파름 |
| Followers | 1 | 10 | 완만 |

Commits·PR·Issues·Reviews는 `1 - 2^(-x)` 곡선이라 **초반에 빠르게 오르고**,
Stars·Followers는 `x / (1 + x)` 곡선이라 **천천히 오릅니다.**
그래서 시작 단계에서는 꾸준한 커밋과 PR이 등급을 올리는 가장 빠른 길입니다.

> 계산식은 [anuraghazra/github-readme-stats](https://github.com/anuraghazra/github-readme-stats)의
> `calculateRank`와 동일하며, 외부 서버 없이
> [`.github/scripts/update-stats.mjs`](.github/scripts/update-stats.mjs)에서 직접 계산합니다.

</details>
